## Лабораторная работа №1: ОПРЕДЕЛЕНИЕ ВРЕМЕНИ РАБОТЫ ПРИКЛАДНЫХ ПРОГРАММ

### Тестовая задача - 1. Алгоритм вычисления числа Пи с помощью разложения в ряд (ряд Грегори-Лейбница) по формуле Лейбница N первых членов ряда

bash-скрипт - запускает программу для определения времени работы программы несколько раз с разными параметроами, чтобы получившееся время было в интервали от 30 до 60 секунд
Для запуска bach-скрипта надо добавить аргумерт в виде уровня оптимизации 
```
./useForLab2.sh O0
```
Или можно запустить саму проуграмму для опеределени времени вручную один раз подавая на вход параметр N:
```
g++ -O0 lab2_clock_gettime.cpp && ./a.out N && rm a.out
```
