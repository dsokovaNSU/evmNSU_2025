## 1. Введение

&nbsp;&nbsp;&nbsp;&nbsp;В современном мире студентам легко потеряться в огромном потоке информации. Постоянный стресс, высокая нагрузка и трудности с оценкой собственного прогресса — справляться с этим самостоятельно становится всё сложнее. Именно поэтому растет потребность в эффективных инструментах для организации учебного процесса.

&nbsp;&nbsp;&nbsp;&nbsp;Одним из таких инструментов станет десктопное приложение, которое поможет студентам формировать учебный план, ставить цели и отслеживать свои достижения. С его помощью пользователи смогут управлять расписанием и выстраивать комфортный темп работы над важными и срочными задачами. Снизить уровень стресса поможет интерактивный милый маскот.

&nbsp;&nbsp;&nbsp;&nbsp;Главная идея проекта — вдохновить пользователей на осознанную организацию своего времени и помочь им навести порядок в учебе, мыслях и чувствах.

## 2. Предметная область проекта

&nbsp;&nbsp;&nbsp;&nbsp;Современный учебный процесс требует от студентов высокого уровня самоорганизации, гибкости и умения справляться с тяжелыми нагрузками. В условиях плотного расписания, обилия дедлайнов и необходимости совмещать учебу с личной жизнью, стандартных подходов к планированию становится недостаточно. Студенты остро нуждаются в комплексных цифровых инструментах, которые не просто фиксируют задачи, но и помогают удерживать фокус и сохранять высокую продуктивность без перегрузок.

### 2.1 Существующие проблемы

&nbsp;&nbsp;&nbsp;&nbsp;**1. Отсутствие единого инструмента.** Информация о парах и заданиях рассредоточена по мессенджерам, вузовским приложениям и блокнотам, а таймеры и цели приходится вести в отдельных сервисах. Из-за этого студент теряет фокус, путается в приложениях и пропускает важные сроки.

&nbsp;&nbsp;&nbsp;&nbsp;**2. Несоответствие специфике учебы.** Большинство таск-менеджеров на рынке созданы для рабочих процессов и бизнеса. Они не учитывают особенности студенческой рутины: пары, сессии и типы учебных заданий. Студент вынужден тратить время на адаптацию приложения под себя.

&nbsp;&nbsp;&nbsp;&nbsp;**3. Монотонный интерфейс.** Существующие планировщики часто имеют скучный дизайн. Такой интерфейс быстро надоедает и никак не мотивирует ежедневно возвращаться к планированию.

### 2.2 Предполагаемое решение

&nbsp;&nbsp;&nbsp;&nbsp;Для решения этих проблем предлагается создать десктопное приложение «StudyHard», которое объединит в себе все необходимые инструменты планирования.

&nbsp;&nbsp;&nbsp;&nbsp;В приложении будут учтены особенности учебной рутины: пользователь сможет гибко настраивать напоминания и дедлайны с учетом расписания пар, сессий и долгосрочных задач (например, для получения автомата). Также «StudyHard» предложит режим фокусировки, в котором можно настраивать параметры таймера под свой темп работы. За мотивацию и снижение тревожности будет отвечать интерактивный маскот-помощник — он будет живо реагировать на успехи студента, подбадривать его и помогать справляться со стрессом.

## 3. Требования к программному решению

### 3.1 Роли

&nbsp;&nbsp;&nbsp;&nbsp;**1. Пользователь**

&nbsp;&nbsp;&nbsp;&nbsp;Пользователь — студент, использующий десктопное приложение «StudyHard» для планирования учебы, ведения задач, работы в режиме фокусировки и взаимодействия с маскотом. Единственная роль в системе.

### 3.2 Функциональные требования для роли Пользователь

#### 3.2.1 Управление расписанием на день

&nbsp;&nbsp;&nbsp;&nbsp;Для добавления или удаления пары на выбранный день пользователь использует кнопки «+ Пара» или «Удалить» (в виде крестика) соответственно.

#### 3.2.2 Сохранение шаблона недели

&nbsp;&nbsp;&nbsp;&nbsp;Пользователь может сохранить статичное недельное расписание для четной/нечетной недели с помощью кнопки «Сохранить неделю».

#### 3.2.3 Создание целей

&nbsp;&nbsp;&nbsp;&nbsp;Для фиксации крупной цели с дедлайном используется кнопка «Новая цель». Внутри созданной цели пользователь может добавлять шаги с помощью кнопки «+ Подзадача».

&nbsp;&nbsp;&nbsp;&nbsp;Сценарий 1: выбор невалидной даты в качестве дедлайна невозможен.

&nbsp;&nbsp;&nbsp;&nbsp;Сценарий 2: пользователь выбирает валидную дату в качестве дедлайна.

#### 3.2.4 Отметка о выполнении

&nbsp;&nbsp;&nbsp;&nbsp;Пользователь может изменять статус целей и подзадач, отмечая их выполнение с помощью чекбокса (галочки).

#### 3.2.5 Добавление напоминаний к парам

&nbsp;&nbsp;&nbsp;&nbsp;Для привязки важной заметки к конкретной паре пользователь нажимает кнопку «+ Напоминание».

#### 3.2.6 Удаление напоминания

&nbsp;&nbsp;&nbsp;&nbsp;Пользователь может удалить неактуальное напоминание из расписания, нажав на иконку крестика рядом с ним.

#### 3.2.7 Персонализация интерфейса и маскота

&nbsp;&nbsp;&nbsp;&nbsp;Для настройки рабочего пространства пользователь нажимает кнопку «Кастомизация» (иконка шестеренки) для входа в режим редактирования. В этом режиме доступны следующие действия:

&nbsp;&nbsp;&nbsp;&nbsp;**1.** Изменение цветовой схемы всего приложения с помощью кнопки «Стиль окна».

&nbsp;&nbsp;&nbsp;&nbsp;**2.** Изменение внешнего вида маскота.

&nbsp;&nbsp;&nbsp;&nbsp;Уникальные визуальные стили приобретаются в «Магазине» за заработанные баллы.

#### 3.2.8 Запуск режима фокусировки

&nbsp;&nbsp;&nbsp;&nbsp;Для перехода в режим концентрации пользователь нажимает кнопку «Фокус».

#### 3.2.9 Настройка таймера фокуса

&nbsp;&nbsp;&nbsp;&nbsp;Пользователь может адаптировать интервалы работы под свой темп с помощью выбора из предложенного списка и установить их количество с помощью кнопок в виде стрелок.

#### 3.2.10 Покупка улучшений за баллы

&nbsp;&nbsp;&nbsp;&nbsp;Для перехода к товарам пользователь нажимает кнопку «Магазин» (иконка в виде павильона). В открывшемся меню он может потратить заработанные баллы на новые элементы для кастомизации маскота и стилей окон рабочего пространства, нажимая кнопку «Купить» под выбранным предметом.

&nbsp;&nbsp;&nbsp;&nbsp;Сценарий 1: Недостаточно средств. Если стоимость предмета превышает сумму на балансе пользователя, кнопка «Купить» остаётся неактивной.

&nbsp;&nbsp;&nbsp;&nbsp;Сценарий 2: Достаточно средств. Если баланса пользователя хватает для покупки выбранного предмета, кнопка «Купить» активна.

### 3.3 Нефункциональные требования

#### 3.3.1 Производительность

- Время запуска приложения — не более 3 секунд на типовой конфигурации.
- Отклик интерфейса на действия пользователя — не более 200 мс.
- Операции с задачами (создание, редактирование, удаление) — не более 500 мс.

#### 3.3.2 Нагрузка

- Приложение рассчитано на одного пользователя (локальное использование).
- Корректная работа при хранении до 1000 задач и событий расписания без заметной деградации.

#### 3.3.3 Надёжность

- Корректное завершение работы без потери данных.
- Периодическое автосохранение данных (не реже одного раза в 30 минут).

#### 3.3.4 Безопасность

- Валидация пользовательского ввода во всех формах.
- Корректная обработка исключений без раскрытия внутренних деталей системы пользователю.

#### 3.3.5 Масштабируемость и расширяемость

- Архитектура приложения — модульная.
- Настройки приложения (тема, интервалы напоминаний, длительность сессии фокуса) хранятся отдельно и изменяются без пересборки.

#### 3.3.7 Удобство использования

- Интерфейс на русском языке.
- Поддержка полноэкранного режима

#### 3.3.8 Переносимость

- Поддержка основных настольных ОС: Windows, macOS, Linux.

#### 3.3.9 Документация

- Код снабжён комментариями к ключевым модулям и функциям.
